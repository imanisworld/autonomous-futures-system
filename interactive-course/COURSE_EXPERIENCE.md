# Interactive Course Experience

## Primary Tracks

| Track | Experience |
|---|---|
| Operator | Configure, test, deploy, and operate the supplied paper system |
| Builder | Implement and understand the system module by module |
| Advanced | Extend storage, dashboards, review tools, and broker simulation |

## Lesson Structure

Each lesson contains:

1. A focused explanation
2. A decision or implementation task
3. An observable verification step
4. A defined deliverable

## Interaction Types

- `knowledge_check`: questions with answer explanations
- `worksheet`: policy or design decisions
- `payload_lab`: edit and validate JSON alert payloads
- `code_task`: implement a focused TODO
- `terminal_check`: run a command and interpret the result
- `replay_lab`: execute historical data and review behavior
- `capstone_gate`: demonstrate a required capability

## Progress Rules

- Module 0 safety work is required for every track.
- A lesson completes after its verification and deliverable are recorded.
- A failed check should teach the reason and allow another attempt.
- Advanced lessons are optional and cannot weaken safety controls.
- Course completion requires a working capstone demonstration.
