# Contributing

Thank you for taking an interest in this educational, paper-only project.

## What Is Welcome

- Reproducible bug reports
- Documentation corrections
- Security reports submitted privately through GitHub

## What Is Not Accepted

- Unsolicited pull requests
- Live-trading or real-order execution changes
- Credentials, account information, webhook URLs, or private logs
- Proprietary strategies or requests for private strategy material
- Claims or guarantees about trading performance

Open the appropriate issue template for public feedback. For vulnerabilities or
exposed credentials, use the private reporting instructions in
[SECURITY.md](SECURITY.md).
