# MNQ sustained-trend existing-strategy audit — preregistration (2026-09-22)

**AUDIT ONLY / RESEARCH ONLY / NO EXECUTION AUTHORITY.**

## Question

Can any existing MNQ LONG setup family that actually appeared during the 2026-09-21 sustained up move produce a realistic, repeatable entry stream across the existing 15-minute historical corpus?

This study is not permission to create a new strategy, change a gate, or reopen a closed strategy. It is a fixed audit of existing definitions.

## Frozen families

Evaluate these existing `strategy.shadow_setups` identities independently:

- `ema_pullback_trend`
- `impulse_first_pullback_observed`
- `strat_22_continuation_observed`
- `trend_consolidation_break_observed`

LONG only. No parameter, stop, target, threshold, regime, session, or detector changes are allowed after seeing results.

Canonical 4HR Re-Trigger and 60M 3-2-2 First Live are **not** regenerated by this script because they already have separate canonical evidence paths. Their existing verdicts remain unchanged and must be compared separately after this audit.

## Population

Use the full available audited MNQ 15-minute corpus supplied to the script. The report must record:

- input path;
- file count;
- first and last date;
- exact family list;
- mechanics below.

Do not cherry-pick 2026-09-21 or select only known trend days. That day motivated the question but is not the test population.

## Mechanics

Each family is a separate arm so one family's activity cannot steal capacity from another.

For every arm:

- use the existing `evaluate_shadow_setups` detector without altering its definition;
- preserve causal bar order;
- one position open at a time;
- maximum 3 filled trades per observation day;
- repeated identical geometry within a day is consumed once;
- evaluate entry once at the decision-bar close;
- entry model = canonical `PaperBroker` IOC-limit semantics;
- MNQ IOC tolerance = 32 ticks;
- adverse entry/stop slippage = 1 tick;
- one contract;
- original candidate stop and target;
- no breakeven trail;
- no runner;
- pessimistic stop-first handling when one later bar contains both stop and target;
- only later bars may resolve a decision-close entry;
- unresolved positions at the end of the observation day remain OPEN and are not assigned fantasy P&L;
- round-turn commission = $1.48 on terminal filled outcomes.

The audit script uses the PaperBroker simulator implementation without the public mirror hook, so running the research cannot submit or mirror any order.

## Frozen review gate

A family may be called **PROMISING BUT UNPROVEN** by this audit only if all are true:

1. at least 30 terminal filled outcomes;
2. net P&L > 0 after commission;
3. PF >= 1.94;
4. first-half net > 0;
5. second-half net > 0;
6. leave-best-day-out net > 0.

Otherwise it does not clear this research gate. A pass does **not** authorize normal paper, DEMO, or live execution; it only justifies a separate prospective paper-lane proposal.
