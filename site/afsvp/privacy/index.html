AFSVP

Privacy

Effective September 21, 2026.

Account information

The public website at afsvp.com has no user accounts. The application at app.afsvp.com is operator-only; it does not offer public sign-up and does not collect names, email addresses, or passwords from visitors.

Technical logs

The web server records standard access logs for every request: IP address, browser or user-agent string, requested path, timestamp, response status, and errors. Security-relevant events such as rejected webhook posts, rate-limit hits, and failed access attempts are also logged. These logs are used only for security, reliability, and troubleshooting.

Cookies, storage, and analytics

afsvp.com sets no cookies and uses no analytics or advertising. app.afsvp.com may set a session cookie when an operator signs in to a protected area; that cookie holds an opaque token, not a password. Neither site uses third-party analytics, tracking pixels, or advertising cookies.

Payment data

AFSVP does not sell anything on this site and does not collect payment information.

Trading and broker data

Visitors cannot connect brokerage accounts. The operator's own demo trading and monitoring data is processed by private backend systems for research, audit, and system-health purposes. That data is not personal data about visitors.

Support and contact messages

There is no contact form. If you email or open a GitHub issue or security report, the content you send (and your address or username) is kept as long as needed to respond and to keep a record of the report.

Retention

Web server access logs are rotated daily and kept for 14 days. Application logs, audit records, and research journals are kept indefinitely because they are the evidence base for the project. Security reports are kept indefinitely.

Who data is shared with

Technical data may be processed by the providers needed to run the site: the hosting provider (server and network), the TLS certificate authority, Google Fonts (font files are loaded from Google servers, which see your IP address and user agent), and GitHub (if you file an issue or security report). Operational notifications are sent to a private Discord channel; those messages describe system state, not visitors. No data is shared with advertisers or data brokers.

Sale of personal data

AFSVP does not sell personal data.

Changes

This policy is updated when the site or its integrations change. The effective date above identifies the current version.
