Status

Public status surfaces are intentionally narrow, read-only, and separate from private operator dashboards.

Public status

The approved public status surface may expose only sanitized service posture: advisory-only mode, scheduler health, read-only market-data posture, and aggregate recent counts.

Never public

Broker credentials, account state, execution controls, trading journals, raw scan rows, contracts, tickers, Signa payloads, database paths, and localhost ports must remain private.

Service separation

afsvp.com is the static public website. status.afsvp.com is reserved for approved read-only status routes. hooks.afsvp.com is reserved for authenticated TradingView webhook ingestion.
