How to compare
  scanner-script-drift prints   git_blob_sha1=<40 hex>   for every file. That is
  sha1(b"blob <size>\0" + content): the same value as `git hash-object <file>`,
  `git rev-parse <ref>:<path>` and the "sha" field of the GitHub contents API.
  Equal blob sha1 == byte-identical file. (Verified locally: the test fixture copy
  of scripts/feed_gap_alarm.py hashes to 0fc061fa..., the GitHub blob SHA.)
  The same table is embedded in scanner_script_drift.py as KNOWN_BLOBS -> known_as=.
